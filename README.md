# Niki Kandlikar

I work on applied ML and data science, mostly Python and scikit-learn, with an interest in causal inference.

### Projects

- **[discount-uplift](https://github.com/niki-kandlikar/discount-uplift)**: uplift modeling to find which customers a discount actually persuades. T-learner and X-learner built from scratch, evaluated with Qini/AUUC, served with FastAPI.
- **[customer-segmentation-kmeans](https://github.com/niki-kandlikar/customer-segmentation-kmeans)**: k-means segmentation with k chosen by silhouette score.
- **[house-price-prediction](https://github.com/niki-kandlikar/house-price-prediction)**: linear regression pipeline with feature engineering and leakage-safe preprocessing.
